# Entitler SDK for Dart and Flutter

The official Entitler SDK for Dart and Flutter.

It isn't available yet. This repository is where the SDK will live; there's no code to install or use.

It will be published to pub.dev as `entitler`. The package there now is an empty placeholder that reserves the name.

Entitler helps SaaS teams manage plans, feature access, usage limits and customer grants. Learn more at [entitler.co](https://entitler.co).
